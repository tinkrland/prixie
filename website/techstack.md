# technology stack

## tanstack start

tanstack start provides server rendering and file-based routing in one react application. it supports route-level metadata and leaves room for server functions when the product moves beyond the public shell.

## react

react provides small, composable interface components. shared structures are extracted only when they repeat or establish a clear product pattern.

## typescript

typescript documents component contracts and catches route, prop, and data shape errors before release.

## tailwind css

tailwind css version 4 provides utility generation from a css-first theme. semantic tokens remain in the global stylesheet so visual roles stay consistent across the product.

## lucide

lucide provides restrained, accessible interface icons. the site uses icons only when they add meaning, not as decoration in place of clear writing.

## vite

vite powers local development and production compilation. its fast feedback loop keeps interface work direct while still producing optimized output.
